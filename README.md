# Personal Portfolio Website

A responsive personal portfolio website built using **HTML, CSS, and JavaScript**. The website showcases my skills, projects, education, and other professional information in a clean and simple design.

## 🚀 Features

* Responsive and user-friendly design
* About Me section
* Skills section
* Projects section
* Education section
* Contact section
* Clean navigation
* Mobile-friendly layout

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive functionality
